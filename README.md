A make.fun entry for the **Weirdest Job Title: Blind Judge Showdown** competition.

`main.py` writes a single job title — the weirdest one we could think of — to `/output/entry.txt`. A blind judge compares titles two at a time and picks the weirder, funnier one.

## The entry

> Professional Eulogist for Other People's Goldfish

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
